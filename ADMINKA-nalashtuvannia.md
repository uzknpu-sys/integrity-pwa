# Адмін-панель і динамічний контент — налаштування

Що додано:
- **admin.html** — панель адміністратора: статистика, додавання новин і відео,
  перелік користувачів із позначкою push.
- Новини й відео тепер **читаються з Firestore** — адмін додає, у застосунку
  з'являється автоматично.

═══════════════════════════════════════
КРОК 1. Призначити адміністратора
═══════════════════════════════════════

1. Спершу зареєструйте у застосунку (index.html) звичайний акаунт, який буде
   адмінським. Наприклад, логін: admin
2. Відкрийте файл admin.html у текстовому редакторі.
3. Знайдіть рядок:
       const ADMIN_LOGIN="admin";
   Впишіть туди ваш адмінський логін (той самий, що зареєстрували).
4. Збережіть і залийте admin.html на GitHub.

Адмінка відкривається за адресою:
   https://uzknpu-sys.github.io/integrity-pwa/admin.html

═══════════════════════════════════════
КРОК 2. Оновити правила безпеки Firestore
═══════════════════════════════════════

Firebase Console → Firestore Database → вкладка Rules → вставте це і Publish.
Замініть admin НА ВАШ адмінський логін у двох місцях (рядки з isAdmin).

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    function isAdmin() {
      return request.auth != null
        && request.auth.token.email == 'admin@integrity-app.local';
    }

    // Профілі: кожен бачить свій; адмін бачить усіх
    match /users/{uid} {
      allow read: if request.auth != null && (request.auth.uid == uid || isAdmin());
      allow write: if request.auth != null && request.auth.uid == uid;
    }

    // Новини: читають усі авторизовані; пише лише адмін
    match /news/{id} {
      allow read: if request.auth != null;
      allow write: if isAdmin();
    }

    // Відео: читають усі авторизовані; пише лише адмін
    match /videos/{id} {
      allow read: if request.auth != null;
      allow write: if isAdmin();
    }
  }
}

⚠️ У рядку isAdmin замініть admin@integrity-app.local на ваш логін
   + @integrity-app.local. Наприклад, якщо логін «lozovyi», то буде
   lozovyi@integrity-app.local.

═══════════════════════════════════════
ЯК КОРИСТУВАТИСЯ
═══════════════════════════════════════

Додати новину:
   admin.html → увійти → «Додати новину» → заголовок + текст → Опублікувати.
   Вона одразу з'явиться у вкладці «Новини» застосунку.

Додати відео:
   admin.html → «Додати відео» → назва + посилання YouTube → Опублікувати.
   З'явиться у вкладці «Матеріали».

Подивитися користувачів:
   admin.html → внизу список усіх + позначка, хто ввімкнув push.

═══════════════════════════════════════
ПРО ЩО ПАМ'ЯТАТИ
═══════════════════════════════════════

• Це працює на безкоштовному Spark — Blaze не потрібен.
• Push-РОЗСИЛКА новин (щоб при додаванні новини всім прийшло сповіщення)
  поки НЕ автоматична — спершу треба полагодити помилку «API key not valid»
  з push. Зараз новина з'являється в застосунку, але push сам не йде.
  Коли push запрацює — додамо автоматичну розсилку.
• AI-помічник досі «в розробці» (чекає на Blaze + Gemini).
